# itch.io beta release

Run:

```bash
npm run package:itch
```

Upload `release/itch/apex-evolve-beta.zip` as an **HTML Game**. Choose **Click to launch in
fullscreen**, enable the fullscreen button, mark the game as desktop-only, and use the itch page's
donation setting. The archive puts `index.html` at its root and validates itch.io's file and size
limits before packaging.

Suggested short description:

> A tactical browser tank shooter where six enemy specialists breed, mutate, and learn after every
> generation. Fight the evolving squad or challenge a single escalating rival.

Controls: WASD move, mouse aim, click fire, Q switch cannon/mortar, C smoke, F flash, V camera,
Shift sprint, M mute.
